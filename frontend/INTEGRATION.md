## 遇到的问题与处理

- 原始目录有其他会话未提交的后端更改：在独立 worktree 联调，未 stash、提交、覆盖这些改动。
- 工作目录起初没有前端实现：新增前端模块，不改共享契约或后端文件。
- 开发阶段 API 与页面端口不同：由 Vite 代理 `/api`，无需开放后台跨域。
- 网络请求失败不能判断写入是否发生：页面不自动重试创建/编辑，保留信息并提示先刷新确认，避免重复操作。
- 原生弹窗的初始焦点在开发模式下不稳定：在弹窗实际打开后显式聚焦名称输入框，复测通过。
- 生产静态文件需要部署方配置 `/api` 代理，Vite 的代理只在 dev/preview 进程中生效。

本批没有发现阻塞任务列表、详情、创建、编辑的后端接口问题。
最终多人跨机器连接同一个后台、MCP 客户端流程、尚未实现的页面功能不在本次验证范围内。
